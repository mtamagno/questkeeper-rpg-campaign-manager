QuestKeeper 1.1 replaces the terminal-first installation path with a guided,
local setup experience for Windows, macOS and Linux.

## Highlights

- Standalone setup builds for Windows x64, Linux x64, macOS Intel and macOS
  Apple Silicon.
- A bilingual English/Italian setup interface that opens locally in the default
  browser and explains every action before it runs.
- A private Node.js 24 runtime stored inside the QuestKeeper folder: no prior
  Node installation and no administrator privileges are required.
- Official `nodejs.org` downloads verified against the published SHA-256
  checksum before extraction.
- Optional desktop launchers for Campaign Manager and the player Companion.
- Platform-specific release archives, all covered by one published checksum
  manifest.

## Download and begin

Choose the archive matching the computer:

- `windows-x64.zip`: extract it, then open `QuestKeeper-Setup.exe`;
- `macos-intel.tar.gz`: extract it, then Control-click **QuestKeeper Setup.app**
  and choose **Open**;
- `macos-apple-silicon.tar.gz`: use the same flow on Apple Silicon Macs;
- `linux-x64.tar.gz`: extract it and open `questkeeper-setup` (mark it
  executable first if the archive tool removed that permission).

The wizard prepares the verified private runtime, installs the locked project
dependencies, creates launchers if requested and can open Campaign Manager.
AI providers and model downloads remain separate, explicit Manager choices.

Read the [Installation Guide](../INSTALLATION-GUIDE.md) for screenshots,
integrity verification and troubleshooting.

## Trust and known boundaries

- The first binaries are not commercially code-signed. Windows SmartScreen or
  macOS Gatekeeper may show a warning; the guide documents how to inspect and
  open the download deliberately.
- The setup server binds only to `127.0.0.1` and uses a random session token.
- QuestKeeper ships no published adventures, commercial rulebooks or protected
  third-party artwork.
- Campaign data remains local unless the GM explicitly publishes it or chooses
  a remote provider.
