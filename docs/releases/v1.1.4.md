## Native setup repaired

- The Node.js 26 standalone setup now embeds runtime-selection logic without a
  filesystem-relative module lookup.
- Its build transform accepts both LF and Windows CRLF source checkouts, with a
  dedicated regression for both forms.
- Windows, Linux, macOS Intel and macOS Apple Silicon packages must all finish
  their setup smoke tests before the release is published.
- The failed `v1.1.3` packaging tag remains immutable and was never published
  as a GitHub Release; `v1.1.4` supersedes it.

## A steadier Campaign Manager

- Remote AI support is capability-based, with OpenAI-compatible xAI/Grok and
  native Gemini paths plus a documented provider research matrix (#1, #8).
- Campaign languages use a searchable selector; partial translations remain
  valid, and manual or AI-assisted drafts stay reviewable before apply (#2,
  #9, #10).
- Ruleset profiles rename game concepts, and character race/class-style fields
  offer native searchable choices without blocking custom or imported values
  (#3, #7).
- Entity IDs are generated, stable and campaign-wide unique; advanced users can
  still inspect them (#13, #14).
- Saved palettes refresh the Companion visibly and preview launch uses one
  readiness model (#5, #6).

## A safer local setup

- QuestKeeper uses Node.js 26 throughout setup, native packages and CI. A
  compatible system installation can be reused instead of silently downloading
  another runtime (#4).
- The Companion shortcut launches the intended destination (#12).
- Setup and local QuestKeeper services have explicit, bounded shutdown paths
  instead of leaving hidden processes behind (#11).

Node.js 26 is still the upstream Current line on this release date and is
scheduled to enter Active LTS on 28 October 2026; QuestKeeper does not label the
runtime itself LTS early.

## A better Companion

- Recent pages, favourites and **Continue reading** remember a bounded trail on
  the current device without reading protected content.
- Route changes are announced and focused consistently; menus and dialogs trap
  and restore focus, while high-contrast modes retain visible affordances.
- Images declare loading intent, fonts no longer block first text, and generated
  output is held to executable initial-load, chunk and image budgets.
- Weekly dependency/runtime and monthly AI-provider reviews now have recorded
  evidence and a repeatable cadence (#15).

## Download

Choose `questkeeper-v1.1.4-windows-x64.zip` for Windows. Linux x64, macOS Intel
and macOS Apple Silicon archives are built from the same tagged source. Verify
the selected archive against `SHA256SUMS.txt` before opening it.

Read the [Installation Guide](https://github.com/mtamagno/questkeeper-rpg-campaign-manager/blob/v1.1.4/docs/INSTALLATION-GUIDE.md) for the guided setup flow.
