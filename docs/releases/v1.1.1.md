QuestKeeper 1.1.1 is a focused Windows setup repair. It preserves every feature
introduced by Lanternwake while making the optional desktop launchers reliable
on real-world user and installation paths.

## Fixed

- Campaign Manager and Companion `.lnk` files are now created through dedicated
  environment values instead of appending paths to a PowerShell command.
- Windows user names, Desktop folders and extracted QuestKeeper paths may contain
  spaces without being interpreted as PowerShell syntax.
- The setup now creates the selected Desktop directory if it is absent.
- A Windows integration test creates both real shortcuts inside a temporary path
  containing several spaces, then verifies that both files exist.

## If setup 1.1.0 stopped at “Creating the Campaign Manager shortcut”

Your private Node.js runtime and locked dependencies were already installed
successfully; no campaign data was damaged. Download the `v1.1.1` Windows
archive, extract it, open `QuestKeeper-Setup.exe` and run setup again. The wizard
will reuse the prepared runtime when it is present and finish the shortcut step.

As a temporary 1.1.0 workaround, rerun setup with both shortcut options disabled,
then open Campaign Manager from the extracted QuestKeeper folder.

## Download

Choose `questkeeper-v1.1.1-windows-x64.zip` for Windows. macOS and Linux archives
are rebuilt from the same verified source so all platforms remain aligned. Check
the downloaded archive against `SHA256SUMS.txt` before opening it.

Read the [Installation Guide](https://github.com/mtamagno/questkeeper-rpg-campaign-manager/blob/v1.1.1/docs/INSTALLATION-GUIDE.md) for the complete setup flow and platform notes.
