# QuestKeeper 1.1.5 · Storyforge — The Living Character (LTS)

**Release channel · LTS**

QuestKeeper 1.1.5 is the recommended stable release for long-running tables.
Storyforge turns a static campaign archive into a dependable character toolkit:
players can see what changed, find the rules they use and return to the exact
story context that gives those mechanics meaning.

## Characters that visibly grow

- Compare any two recorded character levels in a responsive, accessible view.
- See gained and lost spells, features, equipment and changed statistics without
  rewriting immutable history.
- Return directly to **My Character** and resume a safe sheet or notebook reading
  position without storing protected content.
- Search the rules used by one character, then mark favourites, prepared entries,
  usage notes and personal references on the current device.
- Scan current HP, AC, currency, finite resources, structured inventory,
  attunement and explicitly linked signature equipment at the table.

## Story context with evidence

- Character profiles now combine at-a-glance identity, illustrated chapters,
  directional bonds, favourite moments and source-linked signature items.
- NPC dossiers show only the relationships and feelings the party can reasonably
  perceive, including NPC-to-NPC bonds.
- Optional character notebooks support owner-specific art direction, protected
  page sequences, keyboard page turning and an accessible in-page lightbox.
- Around-the-table memories are organised by session and kept separate from
  canonical in-character events.
- Campaign, phase, session and recap-block moods inherit predictably without
  exposing unpublished milestones.

## A safer and clearer Campaign Manager

- Mutable campaigns and private packages live outside replaceable application
  files, with visible storage paths, backups and recoverable migration from
  1.1.4.
- Companion preview start, health, stop and complete shutdown use one bounded
  lifecycle, including installations under paths containing spaces.
- Optional AI setup can be deferred; modal validation remains visible and
  campaign IDs stay generated unless an advanced author chooses otherwise.
- A neutral Campaign Library, canonical game-system identity and balanced wide
  layouts make campaign administration easier to understand.
- Manager appearance is a user preference, while accessible custom Companion
  palettes remain campaign-owned presentation.

## Rules, language and local ownership

- Compendium packages have namespaced identity, explicit provenance and
  fail-closed publication boundaries.
- QuestKeeper ships only a reviewed redistributable baseline and keeps custom
  local packages private by default.
- Entity translation batches are reviewable, resumable and reversible; manual
  authoring remains available throughout.
- Pronouns remain optional, language-aware and independent from ruleset sex or
  gender fields.

## Resolved field feedback

Storyforge contains the complete QuestKeeper 1.1.5 milestone, including issues
#19 through #39. Every included fix keeps its original `reported-in:1.1.4`
context and is marked `resolved-in:1.1.5` after artifact verification.

## Upgrading from 1.1.4

Run the new guided setup over the existing installation. QuestKeeper prepares a
recoverable copy of mutable campaign data before switching to the user-owned
storage root. The application, private Node.js runtime and generated previews
remain replaceable; campaigns, backups and private compendia do not.

## Download

Choose `questkeeper-v1.1.5-windows-x64.zip` for Windows. Linux x64, macOS Intel
and macOS Apple Silicon archives are built from the same tagged source. Verify
the selected archive against `SHA256SUMS.txt` before opening it.

Read the [Installation Guide](https://github.com/mtamagno/questkeeper-rpg-campaign-manager/blob/v1.1.5/docs/INSTALLATION-GUIDE.md) for the guided setup and migration flow.
