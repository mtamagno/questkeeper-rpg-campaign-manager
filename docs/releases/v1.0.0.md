QuestKeeper's first stable public release turns a campaign folder into a living,
self-hosted home for the whole tabletop group.

## Highlights

- A polished player Companion for characters, NPCs, relationships, maps,
  session stories, galleries and private character sections.
- A local Campaign Manager with guided campaign setup, editing, preview,
  backups and GitHub Pages or direct FTPS publishing.
- English and Italian Manager journeys plus campaign content in any configured
  language.
- Optional local or remote AI assistance for editable prose and image drafts;
  manual authoring remains a complete first-class workflow.
- Character imports from sheet images or shared Roll20 print views, always
  reviewed before saving.
- Discord Session Scribe support alongside ordinary handwritten notes.
- Player and Game Master first-visit paths, accessible fantasy UI and curated
  neutral, heroic and gothic campaign palettes.

## Download and begin

1. Download the ZIP on Windows or the TAR.GZ on macOS/Linux from this release.
2. Extract the complete `questkeeper-v1.0.0` folder.
3. Install Node.js 24 if needed.
4. Open `setup.bat` on Windows, `setup.command` on macOS or `setup.sh` on Linux.

The first launch installs project dependencies, opens the local Manager and
guides you through creating or importing a campaign. AI is optional and no
model is downloaded without an explicit choice.

Read the [Installation Guide](https://github.com/mtamagno/questkeeper-rpg-campaign-manager/blob/v1.0.0/docs/INSTALLATION-GUIDE.md)
for platform details and troubleshooting.

## Trust and known boundaries

- QuestKeeper ships no published adventures, commercial rulebooks or protected
  third-party artwork.
- Campaign data stays in ordinary local files unless the GM explicitly
  publishes or sends it to a configured remote provider.
- Browser-side protected sections are a table privacy boundary, not encryption.
- Back up `src/campaigns/` before replacing or upgrading an installation.

**Keep the lore. Share the legend. Own the archive.**
