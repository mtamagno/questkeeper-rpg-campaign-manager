QuestKeeper 1.1.2 gives the graphical setup an explicit final action that closes
both its browser-side session and its local executable cleanly.

## Added

- A persistent **Close setup / Chiudi setup** control in the setup header.
- Clear confirmation that the local setup process has ended, including browsers
  that do not allow a page to close its own tab.
- An authenticated loopback shutdown endpoint protected by the same random setup
  token as every other setup action.

## Shutdown behaviour

- The close control is disabled while installation is actively changing files.
- Once idle, complete or failed, closing setup stops the loopback HTTP service
  and terminates `QuestKeeper-Setup` with a bounded graceful shutdown.
- Campaign Manager or Companion instances intentionally launched by the user are
  separate processes and remain available.
- Source and native executable tests now start a real setup process, request an
  authenticated shutdown and require that process to exit successfully.

## Download

Choose `questkeeper-v1.1.2-windows-x64.zip` for Windows. Linux x64, macOS Intel
and macOS Apple Silicon archives are rebuilt from the same verified source.
