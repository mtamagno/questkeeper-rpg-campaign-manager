# Shared character memories

**Roadmap:** Day 16 · 21 November 2026  
**Classification:** shared

A shared memory belongs to one canonical party relationship and links to the
session that supports it. Its stable ID opens a dedicated page where readers can
compare the facts everyone accepts with each participant's authored recollection.

The record contains:

- a campaign-unique ID and canonical session ID;
- at least the two characters connected by the relationship;
- localized title and shared facts;
- at most one authored viewpoint per participant.
- optional points of difference, each with a localized topic and at least two
  attributed participant accounts.

The page links back to both character profiles, the source session and the
relationship. Campaign Manager edits the same record. Validation rejects
unknown sessions or characters, duplicate IDs, repeated viewpoints and missing
localized copy. AI may propose a draft only from explicit evidence and never
turn an inference into a participant's memory.

Conflicting versions are always explicit authored data. QuestKeeper never
derives a disagreement by comparing prose, and it does not choose which account
is true. Campaign Manager keeps the topic and every attributed account editable.

Shared memories are intentionally distinct from a character's diary: the diary
records one person's ongoing reflection, while this page preserves several
recollections of one common event without duplicating the session itself.
