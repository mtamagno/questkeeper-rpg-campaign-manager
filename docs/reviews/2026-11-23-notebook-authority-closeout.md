# 23 November closeout: notebook chronology and campaign authority

**Classification:** shared  
**Roadmap day:** Day 18  
**Issue:** #120 source-complete; release verification still required

## Outcomes delivered

1. Long character notebooks now have a collapsible table of contents and
   chronology without leaving the lazy Character Journal workspace.
2. Readers can narrow authored pages by mood, linked session, related party
   member and intended audience, then restore the unmodified authored order.
3. The Manager can author the same metadata manually, while AI drafts default
   to private and may suggest a date/audience only from explicit source text.
4. A versioned campaign-scoped authority model now defines stable identities,
   roles, effective capabilities, expiry, revocation, two-party ownership
   transfer, legacy-unclaimed migration and privacy-safe public projection.

## Cross-cutting analysis

- Day 19 keepsakes must reference stable notebook/session/memory IDs rather than
  copy reflections, and must never surface a private page through a public card.
- Day 20 research connections may search authored evidence, but missing links
  stay unknown and secrecy remains a hard filter, not an AI guess.
- #121 must enforce this authority contract at a trusted service boundary. The
  local module is deterministic policy input, not proof that a modified client
  is secure.
- #122 should render effective capabilities from the shared decision function;
  it must not re-encode the role matrix in buttons.
- #123 can remove the global Player/GM fork only after campaign selection can
  resolve the current campaign membership.
- #124 owns explicit claim/import UX. The `unclaimed` legacy state prevents the
  first installation or folder opener from silently becoming owner.
- Completed campaigns without notebooks remain valid. The collapsed controls,
  lazy Journal route and filtered single-spread reader prevent archive growth
  from turning character profiles into infinite pages.
- The catalog and reader add 939 public and 1,085 production initial bytes. Only
  the aggregate initial ceilings move, to 511,000 and 560,000 bytes respectively;
  request, largest-asset, deferred-script and image ceilings stay fixed.

## Evidence boundary

The public example uses only original Lantern Road data. Production enriches
Shyra's existing private notebook with links to already-published sessions and
party IDs. No Strahd canon, protected art, password, transcript, credential or
membership registry crosses into the public template.
